# Trabalho_Banco_de_dados

Este projeto foi desenvolvido como pare de uma
ativivdade acadêmica da faculdade, em
colaboração com um colega.

O trabalho consist na criação e organição de
um banco de dados utilizando SQL, com foco em
um sistema de dados.

Neste repositório disponivel o arquivo SQL
utilizando no projeto, contendo a estrutura e os
dados do banco de dados.

Tecnologia utilizanda:

- MySQL/MriaDB
- SQL

Desenvolvimento: Trabalho realizado em dupla.
